# 🤖 ربات اسکالپر هوشمند فیوچرز بیت‌کوین (BTC/USDT Perpetual Scalping Agent)

یک ایجنت معاملاتی کاملاً خودکار، مبتنی بر پایتون ناهمگام (`asyncio`) و هوش مصنوعی **Google Gemini (`gemini-2.5-flash`)** که برای شکار موقعیت‌های اسکالپ روی جفت‌ارز `BTC/USDT:USDT` در صرافی **LBank** (و پشتیبانی یکپارچه از **Binance** و **Bybit**) طراحی شده است.

---

## 🧠 معماری و نحوه کارکرد ربات

1. **تحلیل مولتی‌تایم‌فریم محلی (بدون مصرف بی‌مورد سهمیه جمینای):**
   * هر ۲۰ ثانیه کندل‌های **۱۵ دقیقه** (تشخیص روند با `EMA 9` و `EMA 26`، محاسبه `ATR 14`، `RSI 14` و استخراج خودکار نواحی حمایت و مقاومت) و کندل‌های **۱ دقیقه** (تشخیص واگرایی RSI، برگشت از اشباع خرید/فروش و کندل‌های مومنتوم) به‌صورت محلی با کتابخانه‌های `pandas` و `ta` محاسبه می‌شوند.
   * **صرفه‌جویی در API:** جمینای در هر تیک صدا زده **نمی‌شود**! فقط زمانی که قیمت در تایم‌فریم ۱۵ دقیقه به `EMA 26` یا ناحیه حمایت/مقاومت پولبک بزند **و هم‌زمان** در تایم‌فریم ۱ دقیقه تریگر ورود (واگرایی یا شکست مومنتوم) صادر شود، داده‌ها برای جمینای ارسال می‌گردند تا مصرف روزانه زیر ۴۰ الی ۵۰ درخواست باقی بماند.
2. **مغز متفکر (Gemini Structured JSON Output):**
   * خروجی جمینای با اسکیمای اجباری (`Pydantic`) دریافت شده و مجدداً توسط موتور اعتبارسنجی بررسی و اصلاح می‌شود تا هیچ قیمت ورود یا حد ضرر نامعتبری وارد موتور ریسک نشود.
3. **مدیریت ریسک سخت‌گیرانه (فرمول حساب ۱۰ دلاری):**
   * **ریسک هر معامله:** حداکثر **۴٪ موجودی** (۰.۴۰ دلار روی حساب ۱۰ دلاری) **با احتساب کارمزد ورود، خروج و اسلیپیج**.
   * **لوریج پویا و ایزوله (`10x` تا `35x`):** بر اساس فاصله دقیق نقطه ورود تا حد ضرر، لوریج طوری تنظیم می‌شود که قیمت لیکوئید شدن با فاصله امن بیرون از حد ضرر قرار بگیرد و کل ضرر در صورت استاپ شدن از ۰.۴۰ دلار تجاوز نکند.
   * **حد سود مرحله‌ای + ریسک‌فری خودکار (Stage 1):** در `TP1` (نسبت ۱ به ۱.۵)، ۵۰٪ پوزیشن بسته شده و حد ضرر ۵۰٪ باقی‌مانده به نقطه ورود + کارمزد (Break-Even) منتقل می‌شود.
   * **حد ضرر متحرک (Stage 2 - Trailing Stop):** نیمه دوم پوزیشن با تریلینگ استاپ پویا (ترکیب `EMA 9` و `ATR` تایم‌فریم ۱ دقیقه) دنبال می‌شود تا در پامپ/دامپ‌های شدید بیت‌کوین سودهای ۱.۵ تا ۳+ دلاری شکار شود.
   * **تارگت و قطع‌کن مدار روزانه (Circuit Breakers):**
     * رسیدن به **+۱ دلار سود خالص روزانه (+۱۰٪)** ⬅️ توقف خودکار تا شروع روز جدید UTC و ارسال پیام تبریک در تلگرام.
     * خوردن **۲ استاپ متوالی** یا **−۰.۸۰ دلار ضرر روزانه (−۸٪)** ⬅️ قفل شدن معاملات به مدت **۲۴ ساعت** برای جلوگیری از معاملات انتقامی (Revenge Trading).
4. **ذخیره‌سازی پایدار (SQLite WAL):**
   * تمام وضعیت‌ها (پوزیشن باز، مرحله ریسک‌فری، موجودی شبیه‌ساز، آمار روزانه و تاریخچه معاملات) در فایل `data/state.db` ذخیره می‌شوند؛ بنابراین با ری‌استارت شدن سرور یا کانتینر هیچ پوزیشنی گم نمی‌شود.

## 🔑 بخش اول: آیا هوش مصنوعی می‌تواند خودش کلید API گوگل بگذارد؟

**خیر؛ به ۳ دلیل فنی و امنیتی بسیار مهم، خود شما باید کلیدهای API را بسازید و داخل فایل `.env` قرار دهید:**
1. **عدم وجود کلید عمومی:** گوگل کلید API عمومی یا بدون صاحب ندارد. هر کلید به یک اکانت Google مشخص متصل است و سهمیه رایگان روزانه (Free Tier) روی همان اکانت محاسبه می‌شود.
2. **امنیت سرمایه و تلگرام شما:** اگر کلید اشتراکی یا عمومی در کد قرار داده شود، در لحظه توسط ربات‌های اسکنر مسدود (Revoke) می‌شود یا افراد دیگر به سهمیه و اطلاعات شما دسترسی پیدا می‌کنند.
3. **رایگان و سریع بودن:** ساخت کلید Gemini API در Google AI Studio **کاملاً رایگان** است، نیازی به کارت بانکی بین‌المللی ندارد و کمتر از **۱ دقیقه** زمان می‌برد.

## 🤖 بخش دوم: دریافت توکن ربات تلگرام و `Chat ID` عددی

### گام ۱: ساخت ربات در `@BotFather`
1. در تلگرام عبارت **`@BotFather`** را جستجو کنید (تیک آبی دارد) و دکمه **Start** را بزنید.
2. دستور `/newbot` را ارسال کنید.
3. یک نام دلخواه برای ربات بنویسید (مثلاً: `My BTC Scalper`).
4. یک نام کاربری (Username) انگلیسی که به `bot` ختم شود وارد کنید (مثلاً: `my_btc_scalper_2026_bot`).
5. بات‌فادر پیامی حاوی **HTTP API Token** به شکل زیر به شما می‌دهد:
   ```text
   7123456789:AAHxyz1234567890abcdefghijklmnop
   ```
   این مقدار را کپی کنید؛ این همان `TELEGRAM_BOT_TOKEN` شماست.
6. **بسیار مهم:** روی لینک ربات جدیدتان که بات‌فادر فرستاده کلیک کنید و داخل ربات خودتان یک بار دکمه **Start** را بزنید (در غیر این صورت تلگرام اجازه نمی‌دهد ربات به شما پیام بفرستد).

### گام ۲: پیدا کردن `Chat ID` عددی اکانت خودتان
1. در تلگرام ربات **`@userinfobot`** را جستجو کرده و **Start** را بزنید.
2. ربات بلافاصله یک عدد (مثلاً `987654321`) تحت عنوان **`Id`** به شما نمایش می‌دهد.
3. این عدد را در فایل `.env` جلوی `TELEGRAM_ADMIN_CHAT_ID` قرار دهید.
   * **نکته امنیتی:** ربات طوری کدنویسی شده که **فقط و فقط** به پیام‌های این آیدی عددی پاسخ می‌دهد و اگر فرد غریبه‌ای ربات شما را پیدا کند، کاملاً نادیده گرفته می‌شود.

3. روی دکمه آبی‌رنگ **`Create API key`** کلیک کنید.
4. در پنجره بازشده گزینه `Create API key in new project` را بزنید.
5. یک رشته طولانی که با `AIzaSy...` شروع می‌شود به شما نمایش داده می‌شود. آن را کپی کرده و در فایل `.env` جلوی `GEMINI_API_KEY` قرار دهید.

## 🏦 بخش چهارم: ساخت کلید API امن در صرافی (LBank / Bybit / Binance)

> **💡 نکته طلایی:** اگر فعلاً می‌خواهید ربات را در حالت شبیه‌ساز (`DRY_RUN=True`) تست کنید، **اصلاً نیازی به وارد کردن کلیدهای صرافی ندارید!** ربات بدون کلید صرافی هم قیمت لحظه‌ای و کندل‌های واقعی بازار را می‌گیرد و با ۱۰ دلار مجازی برایتان معامله شبیه‌سازی می‌کند.

وقتی آماده معامله با پول واقعی (`DRY_RUN=False`) شدید:
1. وارد حساب صرافی **LBank** (وب‌سایت یا اپلیکیشن) شوید.
2. ابتدا در بخش **Futures**، حالت مارجین جفت‌ارز `BTCUSDT` را روی **Isolated (ایزوله)** و حالت پوزیشن را روی **One-Way Mode (یک‌طرفه)** قرار دهید.
3. از منوی پروفایل وارد بخش **API Management** شوید و روی **Create API** کلیک کنید.
4. یک نام (مثلاً `ScalperBot`) انتخاب کنید.
5. **تنظیم سطوح دسترسی (Permissions) — بسیار مهم برای امنیت پول شما:**
   * ✅ گزینه **Read (خواندن)** را فعال کنید.
   * ✅ گزینه **Futures / Contract Trade (معاملات فیوچرز)** را فعال کنید.
   * ❌ **هرگز** تیک **Withdraw (برداشت وجه)** را فعال **نکنید**! (با غیرفعال بودن برداشت، حتی اگر کلید شما لو برود، هیچ‌کس امکان خارج کردن پول از حسابتان را ندارد).
6. **محدودسازی IP (توصیه اکید):** زمانی که ربات را روی سرور مجازی (VPS) گذاشتید، آدرس IP سرور خود را در بخش `IP Restriction` وارد کنید تا کلید فقط از روی سرور شما کار کند.
7. مقادیر `API Key` و `Secret Key` را کپی کرده و در `.env` جلوی `EXCHANGE_API_KEY` و `EXCHANGE_API_SECRET` بگذارید.

## 💻 بخش پنجم: آموزش گام‌به‌گام نصب و تست روی ویندوز (حالت شبیه‌ساز Dry Run)

### پیش‌نیاز: نصب پایتون در ویندوز
اگر پایتون روی ویندوز شما نصب نیست:
1. از سایت **[python.org/downloads](https://www.python.org/downloads/)** نسخه **Python 3.11 یا 3.12** را دانلود کنید.
2. **بسیار مهم:** در صفحه اول نصب، حتماً تیک گزینه **`Add python.exe to PATH`** را در پایین پنجره بزنید و سپس `Install Now` را کلیک کنید.

### مراحل راه‌اندازی در PowerShell
1. پوشه پروژه (`d:\MyProjects\Traider`) را باز کنید.
2. یک کپی از فایل `.env.example` بگیرید و نام آن را به `.env` تغییر دهید:
   ```powershell
   Copy-Item .env.example .env
   ```
3. فایل `.env` را با Notepad یا VS Code باز کنید و ۳ مقدار زیر را پر کنید:
   ```ini
   TELEGRAM_BOT_TOKEN=توکن_ربات_تلگرام_شما
   TELEGRAM_ADMIN_CHAT_ID=آیدی_عددی_تلگرام_شما
   GEMINI_API_KEY=کلید_جمینای_شما
   DRY_RUN=True
   ```
   > **نکته برای کاربران داخل ایران روی ویندوز:** چون تلگرام و جمینای در ایران فیلتر هستند، اگر از نرم‌افزارهایی مثل `v2rayN` استفاده می‌کنید، حالت **TUN Mode** را روشن کنید، یا پورت پروکسی محلی آن را جلوی `TELEGRAM_PROXY_URL=http://127.0.0.1:10809` بنویسید.
4. در PowerShell داخل پوشه پروژه، محیط مجازی پایتون را بسازید و کتابخانه‌ها را نصب کنید:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
   *(اگر ویندوز خطای ExecutionPolicy داد، ابتدا دستور `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` را بزنید).*
5. ربات را روشن کنید:
   ```powershell
   python main.py
   ```
6. به محض اجرا، ربات در تلگرام به شما پیام **«🤖 ربات اسکالپر روشن شد»** را می‌فرستد! حالا می‌توانید دستور `/status` را در تلگرام بزنید و عملکرد ربات را ببینید.

## ☁️ بخش ششم: دیپلوی ۲۴ ساعته روی سرور مجازی با Coolify

برای اینکه ربات بدون نیاز به روشن ماندن کامپیوتر شخصی، ۲۴ ساعته با پینگ پایین و بدون مشکل فیلترینگ کار کند:

### گام ۱: آپلود پروژه در یک مخزن خصوصی GitHub
1. در سایت [github.com](https://github.com) یک Repository جدید و **Private (خصوصی)** بسازید (مثلاً `btc-scalper`).
2. کدهای پوشه پروژه را (بدون فایل `.env`؛ چون `.gitignore` از آپلود آن جلوگیری می‌کند) به گیت‌هاب Push کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: BTC Futures Scalper Agent"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/btc-scalper.git
   git push -u origin main
   ```

### گام ۲: ساخت سرویس در پنل Coolify
1. وارد داشبورد **Coolify** روی سرور مجازی (VPS خارج از کشور، مثلاً آلمان یا فنلاند) شوید.
2. وارد **Projects** شوید، یک پروژه بسازید و داخل محیط `production` روی **+ New Resource** کلیک کنید.
3. از بخش **Git Based** گزینه **Private Repository (with GitHub App)** یا **Private Repository (with Deploy Key)** را انتخاب کنید و مخزن `btc-scalper` را وصل کنید.
4. در بخش **Build Pack**، گزینه **`Docker Compose`** را انتخاب کنید (فایل `docker-compose.yml` به‌صورت خودکار شناسایی می‌شود و ولوم پایدار `scalper_data` را روی `/app/data` مانت می‌کند تا دیتابیس SQLite هنگام آپدیت یا ری‌استارت هرگز پاک نشود).

### گام ۳: تنظیم متغیرهای محیطی (Environment Variables) در Coolify
1. در صفحه سرویس خود در Coolify، وارد تب **Environment Variables** شوید.
2. گزینه **Developer View** (یا Bulk Edit) را بزنید و محتویات فایل `.env` خود را آنجا Paste کنید:
   * حتماً روی سرور خارج `TELEGRAM_PROXY_URL=` را خالی بگذارید.
   * ابتدا با `DRY_RUN=True` تست کنید؛ هر زمان از عملکرد راضی بودید، حتی بدون نیاز به تغییر تنظیمات سرور، مستقیماً از داخل تلگرام با دکمه **`🔁 تغییر حالت`** می‌توانید بین حالت شبیه‌ساز و پول واقعی (`LIVE`) سوئیچ کنید!
3. روی دکمه **`Deploy`** در بالای صفحه Coolify کلیک کنید.
4. پس از حدود ۱ دقیقه که ایمیج داکر ساخته شد، وضعیت سرویس روی **`Running (Healthy)`** قرار می‌گیرد و پیام روشن شدن ربات در تلگرام شما دریافت می‌شود.

## 📱 دستورات تلگرام ربات

| دستور / دکمه | عملکرد |
| :--- | :--- |
| `/status` یا **📊 وضعیت** | نمایش موجودی لحظه‌ای، قیمت بیت‌کوین، سود/ضرر امروز، تعداد درخواست‌های جمینای و جزئیات پوزیشن باز |
| `/mode` یا **🔁 تغییر حالت** | تغییر آنی بین حالت **🧪 شبیه‌ساز (Dry Run)** و **💰 واقعی (Live)** با تایید دو مرحله‌ای |
| `/pause` یا **⏸ توقف** | توقف موقت اسکن بازار برای پوزیشن جدید (پوزیشن باز فعلی همچنان تا بسته شدن مدیریت می‌شود) |
| `/resume` یا **▶️ ادامه** | شروع مجدد اسکن بازار |
| `/panic` یا **🚨 بستن اضطراری** | لغو فوری تمام سفارش‌های باز و بستن تمام پوزیشن‌ها با قیمت بازار در مواقع اضطراری |
| `/history` یا **📜 تاریخچه** | نمایش ۱۰ معامله آخر به همراه نرخ برد (Win Rate) و برآیند سود خالص |
| `/resetdry 10` | ریست کردن موجودی حساب شبیه‌ساز به ۱۰ دلار (یا هر عدد دلخواه) و صفر کردن آمار روزانه |
