# ربات اسکالپر بیت‌کوین با Gemini

راهنمای جاری نصب و شروع: [DEPLOY_FA.md](DEPLOY_FA.md).

این نسخه با قیمت زنده قراردادهای OKX معامله کاغذی می‌کند و ورود، خروج، کارمزد، سود و زیان و موجودی مجازی را در SQLite و تلگرام گزارش می‌دهد. پیش‌فرض حساب معاملاتی `lbank` است، ولی داده شبیه‌سازی از `okx` خوانده می‌شود؛ پیام وضعیت نام منبع را نشان می‌دهد. اجرای واقعی فیوچرز LBank در آداپتور CCXT این پروژه پیاده‌سازی نشده و مسدود است. کندل Spot جای قرارداد استفاده نمی‌شود.

## محدودیت جمنای

مدل پیش‌فرض `gemini-3.8-flash` است. طبق سهمیه‌ای که صاحب پروژه در ۱۷ اکتبر ۲۰۲۶ گزارش کرده: ۵ درخواست در دقیقه، ۲۵۰هزار توکن ورودی در دقیقه و ۲۰ درخواست در روز. بودجه داخلی پیش‌فرض ربات ۱۸ درخواست در روز، فاصله ۹۰۰ ثانیه و ۲۰هزار توکن ورودی در دقیقه است. بررسی دستی و خودکار، هر دو حالت معامله و درخواست‌های ناموفق در همین بودجه حساب می‌شوند. SDK تلاش مجدد خودکار ندارد. خطای ۴۲۹ تحلیل جدید را تا نیمه‌شب Pacific متوقف می‌کند؛ مدیریت معامله باز ادامه دارد.

سهمیه در سطح پروژه گوگل مشترک است. استفاده برنامه‌های دیگر با همان پروژه را نیز حساب کنید. [مستندات رسمی](https://ai.google.dev/gemini-api/docs/rate-limits).

## رفتار معاملاتی

حداکثر ۴ ورود در روز، ریسک هدف ۱٪ موجودی برای هر معامله، سقف زیان روزانه ۳٪، توقف پس از دو زیان متوالی، اهرم ۲ تا ۵ و حداکثر ۳۵٪ موجودی برای مارجین. هدف سود روزانه ۲٪ فقط آستانه توقف است؛ سود تضمینی یا بازده اثبات‌شده نیست. کارمزد، لغزش بیشتر از فرض، گپ بازار و هزینه funding می‌توانند نتیجه را بدتر کنند. حساب کوچک ممکن است به حداقل حجم مجاز نرسد؛ ربات برای عبور از آن ریسک را بالا نمی‌برد.

## کنترل از تلگرام

- `/status`: موجودی، منبع قیمت، سهمیه، معامله باز و دلیل توقف.
- `/guide`: راهنمای ساده کار.
- `/testdry`: دو مسیر قیمت نمونه برای بررسی فنی محاسبه سود و ضرر، جدا از حساب اصلی و بدون API.
- `/scan`: بررسی محلی بازار؛ استعلام اختیاری جمنای هم مشمول سهمیه است.
- `/pause` و `/resume`: توقف و ادامه ورودهای تازه؛ مدیریت معامله باز ادامه دارد.
- `/history`: کارنامه معاملات مجازی و واقعی به تفکیک.
- `/resetdry 25`: تنظیم پول مجازی؛ آمار روز و قفل ریسک آزمایشی را نیز پاک می‌کند.

## بررسی آفلاین

```bash
python -m unittest discover -s tests -v
python paper_check.py
python check_setup.py --market-only
```

دستور سوم فقط کندل و قیمت عمومی می‌خواند. تست‌ها سفارشی در بازار ثبت نمی‌کنند. بررسی اتصال و تست موتور، اثبات سوددهی راهبرد یا تأیید اجرای واقعی صرافی نیست.
